PetConnect is a centralized platform for pet owners and service providers, designed to make pet care simple and accessible. The frontend, built with Angular 18 and Bootstrap, provides an intuitive and responsive user interface where users can:

📅 Book Pet Services – schedule appointments for pet sitting, grooming, and training.

🛒 Explore the Marketplace – discover and purchase pet-related products.

🐶 Connect with Providers – easily find and interact with trusted pet service providers.

⚡ Enjoy a Modern UI – responsive layouts and smooth navigation powered by Angular and Bootstrap.

This repository contains only the frontend implementation of PetConnect. It communicates with the backend to deliver a seamless experience for pet owners and service providers.
